Describe the job. Frugal routes it.

Frugal is the open routing layer for AI tools. Your agent makes the call; Frugal picks the provider per policy — cheapest by default, fast or premium when you ask, pinned or denied when compliance says so — with automatic failover and the decision stamped on every result. Your keys. No account.

Intent routing

Or just describe the job.

frugal__execute takes an intent in plain language, classifies it onto a capability — URL and keyword cues, deterministic, no model call — and routes it under your policy. The reason field is the receipt: what was decided, under which policy, and which provider won on which attempt.

live zero-key run, uneditedmcp
frugal__execute "read https://frugal.sh/blog/ and summarize it"

goreadability   $0 ✓ · 710ms

{
  "capability": "extract",
  "provider_used": "goreadability",
  "cost_usd": 0,
  "reason": "URL detected; routed to a page extract;
    policy=cheap: effective cost ascending;
    provider=goreadability won on attempt 1"
}

priority: cheap | balanced | premium maps onto the policies above. A URL intent runs an extract and falls forward to a headless render when the page needs JS, costs summed. The direct tools stay available when the agent already knows the capability.

The routing table

Cost is the flagship policy.

Tool prices haven't fallen the way model prices have. You.com is 5× Serper. A Firecrawl scrape costs as much as the gpt-4o-mini call that consumes it. SearXNG, on your machine, is free. Under the cheap policy Frugal takes the cheapest result — and when a free provider comes up empty, the chain falls through to the next rung instead of handing your agent an empty array. Cost is one policy among several. It's the one with a receipt.

The receipt

See what you kept.

Every call lands in a local ledger — ~/.frugal/usage, plain JSONL, never leaves your machine. frugal stats prints the month. Only the call that actually produced your result earns rack credit; fallback attempts and zero-hit whiffs don't inflate the number.

Get started

Install

One Go binary. No SaaS. No account. No keys required to start — Marginalia, Wikipedia, and go-readability work with an empty environment. Add SERPER_API_KEY, YDC_API_KEY, FIRECRAWL_API_KEY, BROWSERLESS_TOKEN, or SEARXNG_URL to unlock the paid and self-hosted rungs. Releases are cosign-signed; the installer verifies the checksum before moving the binary into place. From this command to your first intelligently routed tool call: under five minutes. 

$ curl -fsSL https://frugal.sh/install | bash

From source

$ git clone https://github.com/brainsparker/frugal.git && cd frugal && make build

Add Frugal to your agent

$ frugal mcp install
# auto-detects Claude Desktop, Cursor, Claude Code.
# merges 'frugal' into each detected config. idempotent.
