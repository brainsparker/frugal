Provider routing for AI agents

Agents pick providers by what's wired in, not by what the call costs. Provider routing fixes that: every search, extract, or browse call walks a ladder — free and local first, cheap paid next, premium only when nothing cheaper returns a result.

These posts cover the mechanics: how routers decide, how fallback chains behave when a rung returns zero hits, and why the default provider for any capability should cost $0. Start with the complete guide to provider routing.
